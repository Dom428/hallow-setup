# Hallow Setup

One window to install, update, start and uninstall the Hallow family - [Hallow Mixer](https://github.com/Dom428/hallow-mixer), [Hallow Hub](https://github.com/Dom428/hallow-hub), [Hallow Vault](https://github.com/Dom428/hallow-vault), [Hallow Overlay](https://github.com/Dom428/hallow-overlay), [Hallow Remote](https://github.com/Dom428/hallow-remote), [Hallow Clips](https://github.com/Dom428/hallow-clips), [Hallow Keys](https://github.com/Dom428/hallow-keys), [Hallow Assist](https://github.com/Dom428/hallow-assist), [Hallow Guard](https://github.com/Dom428/hallow-guard), [Hallow Tasks](https://github.com/Dom428/hallow-tasks), [Hallow Browser](https://github.com/Dom428/hallow-browser), [Hallow VPN](https://github.com/Dom428/hallow-vpn), [Hallow Torrents](https://github.com/Dom428/hallow-torrents), [Hallow Financials](https://github.com/Dom428/hallow-financials), [Hallow Home](https://github.com/Dom428/hallow-home), [Hallow Email](https://github.com/Dom428/hallow-email), [Hallow Gear](https://github.com/Dom428/hallow-gear) and [Hallow Toolkit](https://github.com/Dom428/hallow-toolkit) - plus the [Hallow Shield](https://github.com/Dom428/hallow-shield) browser extension. [Hallow Places](https://github.com/Dom428/hallow-places) (runs on your NAS) and [Hallow Authenticator](https://github.com/Dom428/hallow-authenticator) (a phone app delivered by Hallow Remote) are listed too, with a link - they aren't Windows apps, so there's nothing to install from here.

- A checklist of every Hallow app with its own icon: what it does, the version on your PC and the newest one on GitHub
- **Install / Update** per app: nothing is downloaded until you click. The release zip is checked against the SHA-256 checksum GitHub publishes for it (no checksum or a mismatch = not installed), unpacked to a temp folder, and the app's own `Install.ps1` runs as you - never as admin
- **Hallow Toolkit** installs as admin, so Setup only starts its own installer and Windows asks you (UAC)
- **Install ticked**: several apps in one go, one after another
- **Updates itself** from its own GitHub releases (checksum checked, reopens by itself)
- **Uninstall** per app (the bin button): says what goes and closes the app first. Your settings stay unless you tick **Also remove my settings and data**, and everything goes to the Recycle Bin. Hallow Vault's backups, Hallow Clips' videos and Hallow Keys' password vault are never touched. Hallow Toolkit: Setup starts its own uninstaller (it needs admin) or tells you how to remove it
- **Start with Windows** per app: the app's own `Hallow<App>` value in HKCU\...\Run (`"<exe>" --tray`), the same one its Settings switch writes
- **Hallow Shield (browser extension)**: shows the newest release and the version in its folder (`version.json`, or `manifest.json` for 1.2 and older). **Install / Update** downloads `hallow-shield-chrome-<version>.zip` from Shield's latest GitHub release only when you click, checks it against GitHub's SHA-256 digest (no digest or a mismatch = not installed) and replaces the files in `%LOCALAPPDATA%\Hallow Shield\chrome`. That's safe: nothing of yours is in that folder - Shield keeps its settings, My filters and stats in the browser's own profile. Then a short list of steps: **Open Chrome / Edge / Brave extensions** (starts that browser on its extensions page only when you click, and copies the address in case the browser doesn't open its own pages from outside), **Copy folder path**, and *Developer mode on -> Load unpacked -> pick this folder; after an update, click the reload arrow on Shield's card*. A Firefox copy can go to `...\Hallow Shield\firefox` (Firefox only keeps unsigned add-ons until it restarts). **Uninstall** moves the folder to the Recycle Bin - remove Shield's card in the browser yourself. Since 1.8, a Shield 1.6+ zip brings the **Hallow family bridge** (`bridge\HallowShieldBridge.exe`): after unpacking, Setup runs its `--install`, which copies it to `%LOCALAPPDATA%\Hallow Shield\bridge` and registers it for Chrome, Edge, Brave and Firefox for your Windows user only (HKCU, no admin) - so Hallow Hub and Remote can show what Shield blocked once you turn on *Share counts with Hallow apps on this PC* in Shield (off by default). Uninstall unregisters it too. Setup never changes a browser on its own
- **Command line** (since 1.18), so Hallow Hub's Install button and Hallow Remote can hand one app to Setup:
  - `HallowSetup.exe --install <App>` opens the window and installs or updates that one app at once (the same as clicking its button; `Shield` = the Chrome / Edge / Brave copy). Add `--quiet` for no window: exit code 0 installed or already up to date, 1 failed, 2 unknown app or not a Windows app, 3 Hallow Toolkit (it installs as admin, so it needs the window), 4 its installer is still running. Already up to date = nothing downloaded, unless `--force`.
  - `HallowSetup.exe --update <App>` the same, only when it's installed.
  - `HallowSetup.exe --list [--check] [--json]` every app and part with the installed version (`--check`: the newest on GitHub too); `--out <file>` also writes the answer to a file.
  - `<App>` is the short name, any case, with or without "Hallow " (`hub`, `Hallow Hub`).
- **Downloads only from the family's own GitHub releases**: the zip must come from `https://github.com/Dom428/hallow-<app>/releases/download/...` and match GitHub's SHA-256 - anything else isn't downloaded (since 1.18 the address is checked too)
- **Fits small screens**: never taller than the screen, the app list scrolls, and since 1.18 the window can be resized and maximised (checked at 1366x768)
- **Light and dark mode** (since 1.10): follows the family mode in `%APPDATA%\Hallow\theme.json` (`"mode"`: dark / light / system, written by Hallow Toolkit - Setup only reads it); `system` follows Windows' app mode live. Setup's own **Look** (Follow Hallow / Light / Dark) is saved in `%APPDATA%\HallowSetup\settings.json` and wins

Nothing to install for Setup itself: download **Hallow Setup.zip** from the [latest release](../../releases/latest), unblock and extract it, and run `HallowSetup.exe`.

Built with the C# compiler that ships with Windows (.NET Framework 4.8): run `build.ps1`. No admin needed.

## What's new

- **1.18** - `--install <App>` / `--update <App>` / `--list` for Hallow Hub and Remote (above). Hallow Gear is in the list; Hallow Places and Hallow Authenticator are shown with a link (not Windows apps). Downloads must come from the app's own GitHub release address as well as match the checksum. The window can be resized and maximised. Fixed: a failed install ("... not installed") was shown in green. Tests: the command line against a local stand-in for GitHub (install, up to date, wrong checksum, a foreign address, Toolkit, Places), the catalogue, and the layout at 1366x768; 5-minute kill timeout.
- **1.15** - Hallow Financials (private personal finance in an encrypted vault: bank statement import, budgets, subscriptions, bill reminders - it never moves money) is in the list: install / update with the checksum check, Start with Windows and its own icon. Uninstalling it never touches its encrypted vault or backups, like Hallow Keys.
- **1.17** - Hallow Email (a private email client: one inbox for all your accounts, trackers and phishing blocked, a private spam filter) is in the list: install / update with the checksum check, Start with Windows and its own icon. Uninstalling it never touches your mail on the servers
- **1.16** - Hallow Home (your pets' feeder and fountain, cameras and lock through your own Home Assistant) is in the list: install / update with the checksum check, Start with Windows and its own icon. Uninstalling it never touches Home Assistant on your NAS or your saved snapshots; with "also remove my data" its live-view cache goes to the Recycle Bin too.
- **1.14** - Hallow Torrents (a game-aware torrent client on MonoTorrent that only ever runs over your VPN - every connection locked to it, Defender-checked downloads) is in the list: install / update with the checksum check, Start with Windows and uninstall. Uninstalling it never touches your downloads and removes its per-user .torrent / magnet link handler where it points at Hallow Torrents.
- **1.13** - Hallow VPN (your NordVPN subscription on Windows' own IKEv2 VPN client - game-aware, split tunnel, optional kill switch, no drivers) is in the list: install / update with the checksum check, Start with Windows and uninstall. Uninstalling it disconnects and removes Windows' "Hallow VPN" connection and, if its kill switch is installed, asks Windows (UAC) to let Hallow VPN remove its firewall rules - so the internet isn't left blocked.
- **1.12** - Light mode readability fixes: with a violet or other mid-tone accent, the filled buttons (Install, Update, Install ticked, Uninstall) now use a slightly darker shade of the accent with white text, instead of dark text that was hard to read; a dark accent (e.g. navy) gets white text too. Same rule as Hallow Toolkit. Dark mode is unchanged.
- **1.11** - Hallow Browser (a fast Chromium browser for gamers with Hallow Shield built in) is in the list: install / update with the checksum check and uninstall (it asks nothing about Start with Windows - the browser only runs while its window is open; uninstall also removes its "a browser you can pick" registration, and its browsing data only when you tick the data box). Setup never makes it your default browser.
- **1.10** - Light and dark mode. Setup follows the mode picked in Hallow Toolkit (Light, Dark or Same as Windows - it switches live when Windows does), or pick its own **Look** at the bottom right: Follow Hallow, Light or Dark. The light look uses the family's light palette, a darker shade of your accent for text so it stays readable, and a light title bar.
- **1.9** - Hallow Tasks (a better Task Manager, no admin) is in the list: install / update with the checksum check, Start with Windows and uninstall (the dialog says that startup entries Tasks disabled stay in its backup key).
- **1.8** - The window fits your screen: never taller than the screen's working area (taskbar left out) and kept on it, the app list scrolls, and the Shield steps scroll into view when they open (they were cut off below a 1080p screen). Hallow Shield 1.6: its Hallow family bridge is registered after unpacking, and the steps say what the new fixed extension ID means for an update from 1.5.
- **1.7** - New app icon: a box with a download arrow, in the Hallow family style. Every app in the list (and Hallow Shield) now shows its own app icon instead of a plain symbol.
- **1.6** - Hallow Shield, the browser extension, is in the list: install / update its folder with the checksum check, buttons to open Chrome's, Edge's or Brave's extensions page and copy the folder path, and uninstall to the Recycle Bin.
- **1.5** - Hallow Guard is in the list.
- **1.4** - Hallow Assist is in the list.
- **1.3** - Uninstall any Hallow app from Setup: the app closes first, settings stay unless you tick them, and everything goes to the Recycle Bin. Backups, clips and your password vault are never touched.
- **1.2** - Hallow Keys is in the list.
- **1.1** - Tick apps and click **Install ticked** to install or update them one after another (updates are ticked for you, Toolkit goes last). Hallow Setup updates itself too - same checksum check, then it reopens.
- **1.0** - First version: install, update and start-with-Windows for all seven Hallow apps, with checksum-verified downloads.
